## Shart

n kun davomida bitta aksiya narxini bilasiz: `p[i]`. Har kuni bitta aksiya sotib olish, bitta sotish yoki hech narsa qilmaslik mumkin. Boshida aksiya yo'q va oxirida ham qolmasligi kerak. Maksimal foyda?

## Kirish va chiqish

n (2 ≤ n ≤ 3·10^5), keyin `p` (1 ≤ p ≤ 10^6). Maksimal foyda.

## Misollar

```input
9
10 5 4 7 9 12 6 2 10
```
```output
20
```
```input
20
3 1 4 1 5 9 2 6 5 3 5 8 9 7 9 3 2 3 8 4
```
```output
41
```

## Hintlar

- Bugungi narxda sotish foydali bo'lsa — darhol soting, lekin keyinroq afsuslanish imkonini saqlang.
- Oldin `x` da olib `p` da sotgan bo'lsangiz, keyin `q` narx kelsa, `q - p` qo'shish `x` da olib `q` da sotishga teng.
- Har kun narxni heap'ga qo'shing; sotgan kuningizda — ikki marta.

## G'oya

Min-heap. `top < p` bo'lsa: `ans += p - top`, `top` ni chiqarib, `p` ni qo'shamiz. Har holda `p` ni yana bir marta qo'shamiz.

## Isbot

Ikki nusxa ikki xil kelajakni saqlaydi: biri "bu sotuvni keyinroq qimmatroq narxga ko'chirish" (afsus), ikkinchisi "bugun sotib olish". Har bir heap amali mumkin bo'lgan tranzaksiyalar to'plamini ifodalaydi, va har kuni eng arzon variant bilan juftlash foydani maksimal oshiradi. To'liq isbot — min-cost flow orqali.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        PriorityQueue<Long> pq = new PriorityQueue<>();
        long ans = 0;
        for (int i = 0; i < n; i++) {
            long p = nl();
            if (!pq.isEmpty() && pq.peek() < p) {
                ans += p - pq.poll();
                pq.add(p);
            }
            pq.add(p);
        }
        System.out.println(ans);
    }
}
```

## Shart

n ta bola, og'irliklari `p[i]`. Har kabinaga 1 yoki 2 bola o'tiradi, umumiy og'irlik ≤ x. Minimal kabinalar soni?

## Kirish va chiqish

n x (1 ≤ n ≤ 2·10^5, 1 ≤ x ≤ 10^9), keyin `p` (1 ≤ p ≤ x). Javob.

## Misollar

```input
4 10
7 2 3 9
```
```output
3
```

## Hintlar

- Eng og'ir bola kim bilan o'tirishi mumkin?
- Agar u eng yengil bilan ham sig'masa — u yolg'iz.
- Ikki ko'rsatkich: chapda eng yengil, o'ngda eng og'ir.

## G'oya

Saralab, `p[i] + p[j] ≤ x` bo'lsa ikkalasini, aks holda faqat og'irini o'tqazamiz.

## Isbot

Exchange: optimal yechimda eng og'ir `H` ning sherigini eng yengil `L` ga almashtirish kabinalar sonini oshirmaydi, chunki `L` ning eski sherigi `z` uchun `y + z ≤ y + H ≤ x`.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        long x = nl();
        long[] p = new long[n];
        for (int i = 0; i < n; i++) p[i] = nl();
        Arrays.sort(p);
        int i = 0, j = n - 1, gond = 0;
        while (i <= j) {
            if (i < j && p[i] + p[j] <= x) i++;
            j--;
            gond++;
        }
        System.out.println(gond);
    }
}
```

## Shart

n ta xaridor, i-si `a[i]` o'lchamli kvartira xohlaydi va `|a[i] - b| ≤ k` bo'lsa rozi. m ta kvartira, o'lchamlari `b[j]`. Har kvartiraga ko'pi bilan bitta xaridor. Maksimal nechta xaridor kvartira oladi?

## Kirish va chiqish

n m k (1 ≤ n, m ≤ 2·10^5, 0 ≤ k ≤ 10^9), keyin `a`, keyin `b` (1 ≤ qiymat ≤ 10^9). Javob.

## Misollar

```input
4 3 5
60 45 80 60
30 60 75
```
```output
2
```

## Hintlar

- Ikkala ro'yxatni saralang.
- Eng kichik kvartira eng kichik xaridorga juda kichik bo'lsa, u hech kimga yaramaydi.
- Eng kichik xaridorga eng kichik kvartira juda katta bo'lsa — u xaridorga hech narsa yaramaydi.

## G'oya

Ikki ko'rsatkich: mos kelsa juftlaymiz, kvartira juda kichik — kvartirani o'tkazamiz, aks holda xaridorni.

## Isbot

Saralangan holatda eng kichik xaridor va eng kichik mos kvartirani juftlash "kesishmaydigan" juftlashga olib keladi; har qanday optimal juftlashdagi kesishgan juftlarni almashtirib, shu ko'rinishga keltirish mumkin.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni(), m = ni();
        long k = nl();
        long[] a = new long[n], b = new long[m];
        for (int i = 0; i < n; i++) a[i] = nl();
        for (int j = 0; j < m; j++) b[j] = nl();
        Arrays.sort(a);
        Arrays.sort(b);
        int i = 0, j = 0, cnt = 0;
        while (i < n && j < m) {
            if (Math.abs(a[i] - b[j]) <= k) { cnt++; i++; j++; }
            else if (b[j] < a[i] - k) j++;
            else i++;
        }
        System.out.println(cnt);
    }
}
```

## Murakkablik

Vaqt O(n log n + m log m), xotira O(n + m).

## Shart

n ta chipta, narxlari `h[i]`. m ta xaridor ketma-ket keladi; i-xaridor `t[i]` dan oshmaydigan **eng qimmat** chiptani oladi. Har xaridor uchun chipta narxini yoki -1 ni chiqaring.

## Kirish va chiqish

n m (1 ≤ n, m ≤ 2·10^5), keyin `h`, keyin `t` (1 ≤ qiymat ≤ 10^9). m qatorda javoblar.

## Misollar

```input
5 3
5 3 7 8 5
4 8 3
```
```output
3
8
-1
```

## Hintlar

- "≤ t bo'lgan eng katta" — qaysi TreeMap metodi?
- Bir xil narxli chiptalar bo'lishi mumkin — sonini saqlang.
- Chiptani sotgach, multiset'dan bitta nusxani o'chiring.

## G'oya

`TreeMap<Integer, Integer>` multiset sifatida, `floorKey(t)`.

## Isbot

Greedy qoida shartda berilgan; vazifa — har so'rovni O(log n) da bajarish. Balanslangan daraxt (TreeMap) floor va o'chirishni shunday bajaradi.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni(), m = ni();
        TreeMap<Integer, Integer> ms = new TreeMap<>();
        for (int i = 0; i < n; i++) ms.merge(ni(), 1, Integer::sum);
        StringBuilder out = new StringBuilder();
        for (int i = 0; i < m; i++) {
            Integer p = ms.floorKey(ni());
            if (p == null) out.append(-1).append('\n');
            else {
                out.append(p).append('\n');
                if (ms.merge(p, -1, Integer::sum) == 0) ms.remove(p);
            }
        }
        System.out.print(out);
    }
}
```

## Murakkablik

Vaqt O((n + m) log n), xotira O(n).

## Shart

`a[i]` — i-pozitsiyadan ko'pi bilan nechta qadam oldinga sakrash mumkin. 0-pozitsiyadan oxirgisiga yetish uchun minimal sakrashlar soni? Yetish har doim mumkin.

## Kirish va chiqish

n (1 ≤ n ≤ 10^5), keyin `a` (0 ≤ a ≤ 1000). Minimal sakrashlar.

## Misollar

```input
5
2 3 1 1 4
```
```output
2
```
```input
5
2 3 0 1 4
```
```output
2
```

## Hintlar

- Bitta sakrashda yetiladigan indekslar ketma-ket oraliq hosil qiladimi?
- Ikki sakrashda-chi?
- `curEnd` — joriy qatlam oxiri, `far` — keyingi qatlam oxiri.

## G'oya

BFS qatlamlarini navbatsiz yuritamiz: `i == curEnd` bo'lganda sakrash sonini oshirib, `curEnd = far`.

## Isbot

k sakrashda yetiladigan indekslar — `[0, R_k]` oraliq, va `R_{k+1}` — shu oraliqdan bir sakrashdagi eng uzoq nuqta. Algoritm aynan shu `R_k` larni hisoblaydi, demak birinchi `R_k ≥ n - 1` bo'lgan k — minimal.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = ni();
        int jumps = 0, curEnd = 0, far = 0;
        for (int i = 0; i < n - 1; i++) {
            far = Math.max(far, i + a[i]);
            if (i == curEnd) {
                jumps++;
                curEnd = far;
            }
        }
        System.out.println(jumps);
    }
}
```

Vaqt O(n), xotira O(n).

## Shart

Aylana yo'lda n ta stansiya. i-stansiyada `gas[i]` litr yoqilg'i olasiz, i dan i+1 ga borish `cost[i]` litr talab qiladi. Bo'sh bak bilan qaysi stansiyadan boshlasangiz, aylanani to'liq aylanib chiqasiz? Javob yagona bo'ladi; bo'lmasa -1.

## Kirish va chiqish

n (1 ≤ n ≤ 10^5), keyin `gas`, keyin `cost` (0 ≤ qiymat ≤ 10^4). Indeks (0 dan) yoki -1.

## Misollar

```input
5
1 2 3 4 5
3 4 5 1 2
```
```output
3
```
```input
3
2 3 4
3 4 3
```
```output
-1
```

## Hintlar

- Umumiy yoqilg'i umumiy sarfdan kam bo'lsa — javob yo'q.
- s dan boshlab i da bak manfiy bo'ldi. s va i oralig'idagi stansiyalardan boshlash yordam beradimi?
- Bitta o'tish yetarli.

## G'oya

Bak manfiy bo'lsa, boshlanishni `i + 1` ga ko'chirib, bakni 0 qilamiz.

## Isbot

s dan i gacha har oraliq nuqta j ga bakda `≥ 0` bilan kelgan edik; j dan 0 bilan boshlash yaxshiroq emas, demak ularning hech biri i dan o'tolmaydi. `Σ ≥ 0` bo'lsa, oxirgi boshlanish nuqtasidan aylanma yo'l to'liq o'tiladi.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        long[] gas = new long[n], cost = new long[n];
        for (int i = 0; i < n; i++) gas[i] = nl();
        for (int i = 0; i < n; i++) cost[i] = nl();
        long total = 0, tank = 0;
        int start = 0;
        for (int i = 0; i < n; i++) {
            long d = gas[i] - cost[i];
            total += d;
            tank += d;
            if (tank < 0) { start = i + 1; tank = 0; }
        }
        System.out.println(total < 0 ? -1 : start);
    }
}
```

## Shart

Musbat son satr ko'rinishida berilgan. Undan aynan k ta raqamni o'chirib, eng kichik sonni hosil qiling. Boshidagi nollarni olib tashlang; hech narsa qolmasa — `0`.

## Kirish va chiqish

Bitta qatorda `num k` (1 ≤ k ≤ |num| ≤ 10^5). Natija.

## Misollar

```input
1432219 3
```
```output
1219
```
```input
10200 1
```
```output
200
```
```input
10 2
```
```output
0
```

## Hintlar

- Ikki son solishtirilganda chapdagi raqam muhimroq.
- Agar raqamdan keyin undan kichik raqam kelsa, birinchisini o'chirish foydali.
- Stek bilan bir o'tishda; oxirida k qolsa — oxiridan kesing.

## G'oya

Monoton (kamaymaydigan) stek: `top > c` va `k > 0` bo'lsa, tepani o'chiramiz.

## Isbot

Birinchi `d[i] > d[i+1]` pozitsiyadagi raqamni o'chirish natijani bitta o'chirish uchun minimal qiladi (chapdagi farqli pozitsiya kichrayadi). Stek bu qoidani k marta ketma-ket, har safar yangi satrda qo'llashni bitta o'tishda bajaradi.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        String num = next();
        int k = ni();
        StringBuilder st = new StringBuilder();
        for (char c : num.toCharArray()) {
            while (k > 0 && st.length() > 0 && st.charAt(st.length() - 1) > c) {
                st.deleteCharAt(st.length() - 1);
                k--;
            }
            st.append(c);
        }
        st.setLength(st.length() - k);
        int i = 0;
        while (i < st.length() - 1 && st.charAt(i) == '0') i++;
        String res = st.substring(i);
        System.out.println(res.isEmpty() ? "0" : res);
    }
}
```

Vaqt O(n), xotira O(n).
