## Shart

Kichik lotin harflaridan iborat s satri. s ning shunday subsequence'ini topingki, unda s dagi har bir harf **aynan bir marta** qatnashsin va u leksikografik eng kichik bo'lsin.

## Kirish va chiqish

Bitta satr s (1 ≤ |s| ≤ 10^5). Natija.

## Misollar

```input
bcabc
```
```output
abc
```
```input
cbacdcbc
```
```output
acdb
```

## Hintlar

- Remove K Digits'ga o'xshaydi: tepadagi kattaroq harfni olib tashlash foydali.
- Lekin uni faqat keyinroq yana uchrasa olib tashlash mumkin.
- Har harfning oxirgi uchrash indeksini oldindan hisoblang; stekda bor harfni qayta qo'shmang.

## G'oya

Monoton stek + `last[]` + `inStack[]`.

## Isbot

Natijaning birinchi harfi — shunday eng kichik harfki, undan keyin qolgan barcha harflar hali uchraydi. Stek har qadamda aynan shu shartni tekshiradi: tepadagi harf kattaroq va keyin yana uchrasa — uni hozir qoldirish natijani faqat yomonlashtiradi.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        String s = next();
        int[] last = new int[26];
        for (int i = 0; i < s.length(); i++) last[s.charAt(i) - 'a'] = i;
        boolean[] in = new boolean[26];
        StringBuilder st = new StringBuilder();
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (in[c - 'a']) continue;
            while (st.length() > 0) {
                char top = st.charAt(st.length() - 1);
                if (top > c && last[top - 'a'] > i) {
                    st.deleteCharAt(st.length() - 1);
                    in[top - 'a'] = false;
                } else break;
            }
            st.append(c);
            in[c - 'a'] = true;
        }
        System.out.println(st);
    }
}
```

## Murakkablik

Vaqt O(n), xotira O(1) (26 harf).

## Shart

n ta shahar, m ta yo'l, har yo'lni ta'mirlash narxi c. Barcha shaharlar orasida yo'l bo'lishi uchun ta'mirlashning minimal umumiy narxi? Imkonsiz bo'lsa `IMPOSSIBLE`.

## Kirish va chiqish

n m (1 ≤ n ≤ 10^5, 1 ≤ m ≤ 2·10^5), keyin m qatorda `a b c` (1 ≤ c ≤ 10^9). Javob.

## Misollar

```input
5 6
1 2 3
2 3 5
2 4 2
3 4 8
5 1 7
5 4 4
```
```output
14
```

## Hintlar

- Bu minimal spanning tree.
- Qirralarni narx bo'yicha saralab, sikl hosil qilmaydiganlarini oling.
- Sikl tekshiruvi — DSU. Oxirida n-1 ta qirra olinmagan bo'lsa — graf bog'lanmagan.

## G'oya

Kruskal + DSU (path halving, union by size). Narx yig'indisi `long`.

## Isbot

Cut property: har qadamda olingan qirra ikki komponentni bog'laydigan eng yengil qirra, demak u biror MST'da bor (exchange). Induksiya bilan barcha olingan qirralar bitta MST'ni tashkil qiladi.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    static int[] par, sz;

    static int find(int x) {
        while (par[x] != x) {
            par[x] = par[par[x]];
            x = par[x];
        }
        return x;
    }

    static boolean union(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b) return false;
        if (sz[a] < sz[b]) { int t = a; a = b; b = t; }
        par[b] = a;
        sz[a] += sz[b];
        return true;
    }

    public static void main(String[] args) throws IOException {
        int n = ni(), m = ni();
        int[][] e = new int[m][3];
        for (int i = 0; i < m; i++) { e[i][0] = ni() - 1; e[i][1] = ni() - 1; e[i][2] = ni(); }
        Arrays.sort(e, (x, y) -> Integer.compare(x[2], y[2]));
        par = new int[n];
        sz = new int[n];
        for (int i = 0; i < n; i++) { par[i] = i; sz[i] = 1; }
        long total = 0;
        int used = 0;
        for (int[] ed : e) {
            if (union(ed[0], ed[1])) {
                total += ed[2];
                used++;
            }
        }
        System.out.println(used == n - 1 ? String.valueOf(total) : "IMPOSSIBLE");
    }
}
```

## Murakkablik

Vaqt O(m log m), xotira O(n + m).

## Shart

n ta shahar, m ta bir tomonlama reys (narxi c). 1-shahardan barcha shaharlarga eng arzon yo'l narxini toping. Barcha shaharlarga yetish mumkin.

## Kirish va chiqish

n m (1 ≤ n ≤ 10^5, 1 ≤ m ≤ 2·10^5), keyin m qatorda `a b c` (1 ≤ c ≤ 10^9). n ta son — masofalar.

## Misollar

```input
3 4
1 2 6
1 3 2
3 2 3
1 3 4
```
```output
0 5 2
```

## Hintlar

- Og'irliklar musbat — Dijkstra.
- Masofalar 10^14 gacha — `long`.
- Heap'dagi eskirgan yozuvlarni olinganda tashlab yuboring.

## G'oya

Dijkstra, lazy deletion, qo'shnilik ro'yxati massivlarda (tezlik uchun).

## Isbot

Heap'dan olingan eng kichik masofali yakunlanmagan tugunga boshqa yo'l bilan kamroqqa borib bo'lmaydi: har qanday boshqa yo'l avval masofasi kamida shuncha bo'lgan yakunlanmagan tugundan o'tadi, qirralar esa manfiy emas.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni(), m = ni();
        int[] head = new int[n], nxt = new int[m], to = new int[m];
        long[] w = new long[m];
        Arrays.fill(head, -1);
        for (int i = 0; i < m; i++) {
            int a = ni() - 1;
            to[i] = ni() - 1;
            w[i] = nl();
            nxt[i] = head[a];
            head[a] = i;
        }
        long[] dist = new long[n];
        Arrays.fill(dist, Long.MAX_VALUE);
        dist[0] = 0;
        PriorityQueue<long[]> pq = new PriorityQueue<>((x, y) -> Long.compare(x[0], y[0]));
        pq.add(new long[]{0, 0});
        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            int v = (int) cur[1];
            if (cur[0] > dist[v]) continue;
            for (int e = head[v]; e != -1; e = nxt[e]) {
                long nd = cur[0] + w[e];
                if (nd < dist[to[e]]) {
                    dist[to[e]] = nd;
                    pq.add(new long[]{nd, to[e]});
                }
            }
        }
        StringBuilder out = new StringBuilder();
        for (int i = 0; i < n; i++) out.append(dist[i]).append(i + 1 < n ? ' ' : '\n');
        System.out.print(out);
    }
}
```

## Murakkablik

Vaqt O((n + m) log m), xotira O(n + m).

## Shart

n ta tanga, qiymatlari `x[i]`. Ularning qism-to'plami yig'indisi sifatida hosil qilib **bo'lmaydigan** eng kichik musbat son?

## Kirish va chiqish

n (1 ≤ n ≤ 2·10^5), keyin `x` (1 ≤ x ≤ 10^9). Javob.

## Misollar

```input
5
2 9 1 2 7
```
```output
6
```

## Hintlar

- Saralang. Dastlabki tangalar bilan qaysi sonlar hosil bo'ladi?
- Agar `[1, S]` ning hammasi hosil bo'lsa va keyingi tanga `c ≤ S + 1`, nima bo'ladi?
- `c > S + 1` bo'lsa — javob topildi.

## G'oya

`reach` — hozirgacha hosil bo'ladigan oraliq oxiri. `x ≤ reach + 1` bo'lsa `reach += x`, aks holda to'xtaymiz. Javob `reach + 1`.

## Isbot

Invariant: birinchi i tanga bilan `[1, reach]` dagi har son hosil bo'ladi va `reach + 1` hosil bo'lmaydi. `c ≤ reach + 1` bo'lsa `[c, reach + c]` ham qamraladi va oraliqlar ulanadi. `c > reach + 1` bo'lsa, `reach + 1` ni hosil qilish uchun undan kichik tangalar yetmaydi, katta tangalar esa ortiqcha.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        long[] c = new long[n];
        for (int i = 0; i < n; i++) c[i] = nl();
        Arrays.sort(c);
        long reach = 0;
        for (long x : c) {
            if (x > reach + 1) break;
            reach += x;
        }
        System.out.println(reach + 1);
    }
}
```

## Murakkablik

Vaqt O(n log n), xotira O(n).

## Shart

n ta kub ketma-ket keladi, o'lchamlari `k[i]`. Har kubni tepasidagi kub **o'zidan katta** bo'lgan minoraga qo'yish yoki yangi minora boshlash mumkin. Kublar tartibi o'zgarmaydi. Minimal minoralar soni?

## Kirish va chiqish

n (1 ≤ n ≤ 2·10^5), keyin `k` (1 ≤ k ≤ 10^9). Javob.

## Misollar

```input
5
3 8 2 1 5
```
```output
2
```

## Hintlar

- Kubni qaysi minoraga qo'yish eng xavfsiz?
- Katta tepalar keyingi katta kublar uchun kerak bo'ladi.
- Tepasi kubdan qat'iy katta bo'lgan eng kichik tepa — `higherKey`.

## G'oya

Minora tepalari multiset'da. Kub `x`: `higherKey(x)` bor bo'lsa o'sha tepani `x` ga almashtiramiz, aks holda yangi tepa `x`.

## Isbot

Exchange: kubni kattaroq tepaga qo'ygan yechimda ikki minoraning qolgan qismini almashtirish mumkin — tepalar to'plami "nuqtama-nuqta" kichikroq bo'lib qoladi, bu keyingi har kub uchun kamida shuncha imkoniyat qoldiradi. Minoralar soni — eng uzun kamaymaydigan subsequence (Dilworth).

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        TreeMap<Integer, Integer> tops = new TreeMap<>();
        int towers = 0;
        for (int i = 0; i < n; i++) {
            int x = ni();
            Integer t = tops.higherKey(x);
            if (t != null) {
                if (tops.merge(t, -1, Integer::sum) == 0) tops.remove(t);
            } else towers++;
            tops.merge(x, 1, Integer::sum);
        }
        System.out.println(towers);
    }
}
```

## Murakkablik

Vaqt O(n log n), xotira O(n).

## Shart

n ta mashina, i-si bitta mahsulotni `k[i]` sekundda yasaydi. Mashinalar parallel ishlaydi. t ta mahsulot yasash uchun minimal vaqt?

## Kirish va chiqish

n t (1 ≤ n ≤ 2·10^5, 1 ≤ t ≤ 10^9), keyin `k` (1 ≤ k ≤ 10^9). Minimal vaqt.

## Misollar

```input
3 7
3 2 5
```
```output
8
```

## Hintlar

- T vaqtda nechta mahsulot yasaladi?
- Agar T vaqt yetsa, T+1 ham yetadimi?
- Yig'indi `long`dan chiqmasligi uchun t ga yetishi bilan to'xtating.

## G'oya

Javob bo'yicha binary search, `check(T) = Σ T / k[i] ≥ t`. Yuqori chegara `min(k) · t`.

## Isbot

`check` monoton: T oshsa har mashina yasaydigan son kamaymaydi. Har mashinaning T davomida to'xtovsiz ishlashi — T vaqtdagi maksimal ishlab chiqarish (greedy check).

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    static int[] k;
    static long t;

    static boolean check(long T) {
        long made = 0;
        for (int x : k) {
            made += T / x;
            if (made >= t) return true;
        }
        return false;
    }

    public static void main(String[] args) throws IOException {
        int n = ni();
        t = nl();
        k = new int[n];
        long mn = Long.MAX_VALUE;
        for (int i = 0; i < n; i++) { k[i] = ni(); mn = Math.min(mn, k[i]); }
        long lo = 1, hi = mn * t;
        while (lo < hi) {
            long mid = lo + (hi - lo) / 2;
            if (check(mid)) hi = mid;
            else lo = mid + 1;
        }
        System.out.println(lo);
    }
}
```

## Murakkablik

Vaqt O(n log(min(k) · t)), xotira O(n).

## Shart

n ta musbat sondan iborat massivni k ta bo'sh bo'lmagan ketma-ket bo'lakka bo'ling. Bo'laklar yig'indilarining maksimumi minimal bo'lsin. Shu minimumni toping.

## Kirish va chiqish

n k (1 ≤ k ≤ n ≤ 2·10^5), keyin massiv (1 ≤ x ≤ 10^9). Javob.

## Misollar

```input
5 3
2 4 7 3 5
```
```output
8
```

## Hintlar

- "Maksimumni minimallashtiring" — binary search belgisi.
- S berilgan bo'lsa, har bo'lak ≤ S bo'lishi uchun minimal nechta bo'lak kerak?
- Bo'lakni imkon qadar uzun qiling. k dan kam bo'lak chiqsa ham bo'ladi — ularni bo'lib yuborish mumkin.

## G'oya

`check(S)`: chapdan yurib, sig'maguncha qo'shamiz; bo'laklar soni `≤ k` mi. Pastki chegara — maksimal element, yuqori — umumiy yig'indi.

## Isbot

Bo'lakni imkon qadar uzaytirish hech qachon bo'laklar sonini oshirmaydi ("greedy stays ahead": greedy'ning j-bo'lagi har qanday to'g'ri bo'lishning j-bo'lagidan oldin tugamaydi). `check` S bo'yicha monoton.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    static long[] a;
    static int k;

    static boolean check(long S) {
        int parts = 1;
        long cur = 0;
        for (long x : a) {
            if (x > S) return false;
            if (cur + x > S) { parts++; cur = 0; }
            cur += x;
        }
        return parts <= k;
    }

    public static void main(String[] args) throws IOException {
        int n = ni();
        k = ni();
        a = new long[n];
        long lo = 0, hi = 0;
        for (int i = 0; i < n; i++) { a[i] = nl(); lo = Math.max(lo, a[i]); hi += a[i]; }
        while (lo < hi) {
            long mid = lo + (hi - lo) / 2;
            if (check(mid)) hi = mid;
            else lo = mid + 1;
        }
        System.out.println(lo);
    }
}
```

## Murakkablik

Vaqt O(n log Σ), xotira O(n).
