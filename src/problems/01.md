## Shart

Limonad 5 so'm turadi. Navbatda n ta xaridor, har biri 5, 10 yoki 20 lik bitta pul beradi. Boshida kassada pul yo'q. Har bir xaridorga to'g'ri qaytim bera olasizmi?

## Kirish va chiqish

n (1 ≤ n ≤ 10^5), keyin n ta son (5, 10 yoki 20). `YES` yoki `NO`.

## Misollar

```input
5
5 5 5 10 20
```
```output
YES
```
```input
5
5 5 10 10 20
```
```output
NO
```

## Hintlar

- Faqat 5 va 10 liklar sonini bilish yetarli — 20 lik hech qachon qaytimga ketmaydi.
- 20 ga qaytim 15: ikki xil usul bor.
- Qaysi kupyura "universalroq"?

## G'oya

20 uchun avval `10 + 5`, bo'lmasa `5 + 5 + 5`.

## Isbot

5 lik har qanday qaytimda ishlatiladi, 10 lik esa faqat 20 uchun. `10 + 5` bilan qaytarsak, `5 + 5 + 5` ga nisbatan ikkita 5 lik ortiqcha qoladi va bitta 10 lik kam — bu holat har qanday keyingi xaridor uchun yomon emas: 10 lik o'rniga ikkita 5 lik har doim ishlatilishi mumkin, teskarisi esa yo'q.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        int five = 0, ten = 0;
        boolean ok = true;
        for (int i = 0; i < n; i++) {
            int b = ni();
            if (b == 5) five++;
            else if (b == 10) {
                if (five == 0) ok = false;
                else { five--; ten++; }
            } else {
                if (ten > 0 && five > 0) { ten--; five--; }
                else if (five >= 3) five -= 3;
                else ok = false;
            }
        }
        System.out.println(ok ? "YES" : "NO");
    }
}
```

## Murakkablik

Vaqt O(n), xotira O(1).

## Shart

n ta bola, i-bolaning ishtahasi `g[i]`. m ta pechenye, j-sining o'lchami `s[j]`. Bolaga `s[j] ≥ g[i]` bo'lgan pechenye berilsa, u xursand. Har bolaga ko'pi bilan bitta pechenye. Maksimal nechta bola xursand bo'ladi?

## Kirish va chiqish

n m (1 ≤ n, m ≤ 10^5), keyin `g`, keyin `s` (qiymatlar ≤ 10^9). Javob.

## Misollar

```input
3 2
1 2 3
1 1
```
```output
1
```
```input
2 3
1 2
1 2 3
```
```output
2
```

## Hintlar

- Ikkala massivni saralang.
- Eng kichik pechenyeni kimga berish kerak?
- Eng kichik pechenye eng kam ishtahali bolaga yetmasa, u hech kimga yetmaydi.

## G'oya

Ikki ko'rsatkich: pechenyelarni o'sish tartibida yuramiz, joriy pechenye joriy (eng kam ishtahali) bolaga yetsa — beramiz.

## Isbot

Eng kam ishtahali bolani qanoatlantiradigan eng kichik pechenye bilan qanoatlantirish — kattaroq pechenyelarni boshqalarga qoldiradi. Optimal yechimda u bolaga kattaroq pechenye berilgan bo'lsa, ularni almashtirish hech kimni xafa qilmaydi.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni(), m = ni();
        long[] g = new long[n], s = new long[m];
        for (int i = 0; i < n; i++) g[i] = nl();
        for (int j = 0; j < m; j++) s[j] = nl();
        Arrays.sort(g);
        Arrays.sort(s);
        int i = 0;
        for (int j = 0; j < m && i < n; j++) {
            if (s[j] >= g[i]) i++;
        }
        System.out.println(i);
    }
}
```

## Murakkablik

Vaqt O(n log n + m log m), xotira O(n + m).

## Shart

n ta tayoq, uzunliklari `p[i]`. Bitta tayoqni 1 ga uzaytirish yoki qisqartirish narxi 1. Barcha tayoqlarni bir xil uzunlikka keltirishning minimal narxi?

## Kirish va chiqish

n (1 ≤ n ≤ 2·10^5), keyin `p` (1 ≤ p ≤ 10^9). Minimal narx.

## Misollar

```input
5
2 3 1 5 2
```
```output
5
```

## Hintlar

- Narx — `Σ |p[i] - x|`. Qaysi x?
- x ni 1 ga o'ngga sursak, narx qanchaga o'zgaradi?
- Javob 10^14 gacha — `long`.

## G'oya

x = median (saralangandan keyin o'rtadagi element).

## Isbot

x dan chapda L ta, o'ngda R ta element bo'lsa, x ni 1 ga o'ngga surish narxni `L - R` ga o'zgartiradi. L < R bo'lsa o'ngga surish foydali, L > R bo'lsa chapga. Medianda L va R muvozanatda — yaxshilab bo'lmaydi.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        long[] p = new long[n];
        for (int i = 0; i < n; i++) p[i] = nl();
        Arrays.sort(p);
        long med = p[n / 2], cost = 0;
        for (long x : p) cost += Math.abs(x - med);
        System.out.println(cost);
    }
}
```

## Murakkablik

Vaqt O(n log n), xotira O(n).

## Shart

Festivalda n ta film, har biri `[a, b)` vaqtda. Filmni boshidan oxirigacha ko'rish kerak, bir vaqtda faqat bitta. Maksimal nechta filmni to'liq ko'rish mumkin? Bir film tugagan paytda boshqasi boshlansa — ikkalasini ham ko'rish mumkin.

## Kirish va chiqish

n (1 ≤ n ≤ 2·10^5), keyin n qatorda `a b` (1 ≤ a < b ≤ 10^9). Maksimal filmlar soni.

## Misollar

```input
3
3 5
4 9
5 8
```
```output
2
```

## Hintlar

- Qaysi kalit bo'yicha saralash kerak: boshlanish, uzunlik yoki tugash?
- Eng erta boshlanadigan uzun bo'lishi mumkin.
- Eng erta tugaydiganini olsak, qolganlar uchun ko'proq vaqt qoladi.

## G'oya

Tugash vaqti bo'yicha saralab, `a ≥ lastEnd` bo'lsa olamiz.

## Isbot

"Greedy stays ahead": greedy tanlagan k-film optimal yechimning k-filmidan kechroq tugamaydi (induksiya). Demak greedy kamida optimalcha film oladi.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        int[][] f = new int[n][2];
        for (int i = 0; i < n; i++) { f[i][0] = ni(); f[i][1] = ni(); }
        Arrays.sort(f, (x, y) -> Integer.compare(x[1], y[1]));
        int cnt = 0, lastEnd = 0;
        for (int[] it : f) {
            if (it[0] >= lastEnd) {
                cnt++;
                lastEnd = it[1];
            }
        }
        System.out.println(cnt);
    }
}
```

## Murakkablik

Vaqt O(n log n), xotira O(n).

## Shart

n ta mijozning kelish va ketish vaqtlari berilgan (barcha vaqtlar har xil). Restoranda bir vaqtda eng ko'p nechta mijoz bo'lgan?

## Kirish va chiqish

n (1 ≤ n ≤ 2·10^5), keyin n qatorda `a b` (1 ≤ a < b ≤ 10^9). Maksimal mijozlar soni.

## Misollar

```input
3
5 8
2 4
3 9
```
```output
2
```

## Hintlar

- Har mijozni ikki hodisaga ajrating: kelish va ketish.
- Hodisalarni vaqt bo'yicha saralang.
- Kelishda +1, ketishda -1; hisoblagich maksimumi — javob.

## G'oya

Hodisani bitta `long`ga kodlaymiz: `vaqt * 2 + tur` (1 — kelish, 0 — ketish) va saralaymiz.

## Isbot

Hisoblagich har vaqt momentida aynan restorandagi mijozlar sonini ko'rsatadi — bu greedy emas, sof hisoblash. Greedy qismi — "faqat hodisa nuqtalarini tekshirish yetarli": maksimum doim qandaydir kelish momentida erishiladi.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        long[] ev = new long[2 * n];
        for (int i = 0; i < n; i++) {
            long a = nl(), b = nl();
            ev[2 * i] = a * 2 + 1;
            ev[2 * i + 1] = b * 2;
        }
        Arrays.sort(ev);
        int cur = 0, best = 0;
        for (long x : ev) {
            cur += (x & 1) == 1 ? 1 : -1;
            best = Math.max(best, cur);
        }
        System.out.println(best);
    }
}
```

## Murakkablik

Vaqt O(n log n), xotira O(n).

## G'oya

## Isbot

Eng erta tugaydigan sharni yorish uchun o'q uning ichida bo'lishi shart. Uning oxiri — bu oraliqdagi eng o'ng nuqta, u boshqa sharlarni ham imkon qadar ko'p qamraydi (exchange: o'qni chaproqqa otgan yechimni oxiriga surish hech qaysi sharni yo'qotmaydi).

import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();

        for (int i = 0; i < n; i++) { b[i][0] = nl(); b[i][1] = nl(); }
        Arrays.sort(b, (x, y) -> Long.compare(x[1], y[1]));

## Shart

n ta ish, har birining davomiyligi `a` va deadline'i `d`. Ishlarni ketma-ket bajarasiz, 0 vaqtdan boshlab. Ish f vaqtda tugasa, mukofot `d - f` (manfiy bo'lishi mumkin). Maksimal umumiy mukofot?

## Kirish va chiqish

n (1 ≤ n ≤ 2·10^5), keyin n qatorda `a d` (1 ≤ a, d ≤ 10^6). Maksimal mukofot.

## Misollar

```input
3
6 10
8 15
5 12
```
```output
2
```

## Hintlar

- Umumiy mukofot `Σd - Σf`. Birinchi qism tartibga bog'liqmi?
- Demak `Σf` ni minimallashtirish kerak.
- Qo'shni ikki ishni almashtirsangiz `Σf` qanday o'zgaradi?

## G'oya

Davomiylik bo'yicha saralash (Shortest Processing Time). Deadline'lar tartibga ta'sir qilmaydi.

## Isbot

Qo'shni `x`, `y` da `a[x] > a[y]` bo'lsa, almashtirish `Σf` ni `a[x] - a[y]` ga kamaytiradi. Demak optimal tartibda bunday inversiya yo'q — u davomiylik bo'yicha saralangan.

## Yechim

```java
import java.util.*;
import java.io.*;

public class Main {
    @IO

    public static void main(String[] args) throws IOException {
        int n = ni();
        int[][] t = new int[n][2];
        for (int i = 0; i < n; i++) { t[i][0] = ni(); t[i][1] = ni(); }
        Arrays.sort(t, (x, y) -> Integer.compare(x[0], y[0]));
        long time = 0, reward = 0;
        for (int[] it : t) {
            time += it[0];
            reward += it[1] - time;
        }
        System.out.println(reward);
    }
}
```

## Murakkablik

Vaqt O(n log n), xotira O(n).
